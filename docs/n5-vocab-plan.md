# แผนคำศัพท์ JLPT N5 (สายคำศัพท์)

แผนว่าคำในรายการ N5 อยู่ช่วง (区間) ไหน — ใช้ตอนทยอยเปิดช่วงใหม่ทีละรอบ
ช่วงที่เปิดแล้วอยู่ในโค้ด `src/data/vocab/n5/*.ts` (ข้อมูลจริงอยู่ที่นั่น ไม่ใช่ที่ไฟล์นี้)

## ที่มาของรายการคำ

- รายการ JLPT N5 ของ Jonathan Waller (เว็บ tanos.co.uk ปิดไปแล้ว เผยแพร่แบบ CC BY)
  ได้มาจาก [stephenmk/yomitan-jlpt-vocab](https://github.com/stephenmk/yomitan-jlpt-vocab) ไฟล์
  `original_data/n5.csv` (684 รายการ, CC BY-SA 4.0)
- ใช้แค่ "คำไหนอยู่ใน N5" + คานะ/คันจิ **ไม่ใช้คำแปลภาษาอังกฤษของรายการ** (มีจุดผิดหลายจุด
  และบางคำผูกกับรายการ JMdict ผิดตัว เช่น コップ ไปผูกกับ "cop")
- คำอ่าน/คันจิตรวจกับ JMdict (EDRDG, CC BY-SA 4.0) · ใช้รูปเขียนปัจจุบัน (明い → 明るい, 終る → 終わる)
  และไม่ใส่คันจิให้คำที่ปกติเขียนด้วยคานะ (あなた, ここ, する ฯลฯ)
- ตั้งแต่ปี 2010 ไม่มีรายการคำ N5 อย่างเป็นทางการ — ทุกรายการเป็นการประมาณ

## หลักการ (ผู้ใช้เลือกแล้ว 2026-11-19)

- แบ่งตามหัวข้อ บทละ ~8 คำ (4–10) = 1 สถานี · หลายบทรวมเป็น 1 ช่วง
- **คำซ้ำที่ต่างแค่วิธีอ่าน/วิธีเขียน รวมเป็นการ์ดเดียว** แล้วบอกอีกแบบในหมายเหตุ (ด้านล่างเขียนว่า `ก+ข` หรือ `คำ(คันจิ1/คันจิ2)`)
- คำพ้องความหมาย (เช่น あに กับ おにいさん) เป็นคนละการ์ด ใช้ความหมายไทยตรงกัน แล้วอธิบายความต่างในหมายเหตุ
- **คำเก่าที่แทบไม่ใช้แล้ว** อยู่ช่วงสุดท้าย (むかし)
- ทยอยเปิดทีละ 2–3 ช่วง **ต่อท้ายเสมอ** เพื่อให้เลขสถานีของบทเดิมไม่เปลี่ยน · id ของคำ/บทห้ามเปลี่ยน
