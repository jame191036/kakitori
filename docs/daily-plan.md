# แผนสายชีวิตประจำวัน

หมวด "ใช้ในชีวิตประจำวัน" บนหน้าแรก (`/daily`) — วลีที่ใช้คุยกับคนญี่ปุ่นและใช้ชีวิตในญี่ปุ่น
เรียนเป็นสายวลีแบบเดียวกับสายท่องเที่ยว (ช่วง → บท (สถานี) → วลี · ความคืบหน้า `ProgressData.scripts['daily']` · สถานี D01…)

## สิ่งที่ผู้ใช้เลือก (2026-11-23)

- **เนื้อหา:** ผสมทั้งคุยกับคนญี่ปุ่น (แนะนำตัว ชวน ปฏิเสธ คุยเล่น) และใช้ชีวิตในญี่ปุ่น (ที่ทำงาน ที่พัก ธุระ)
- **รูปแบบ:** สายวลี + **บทสนทนาตัวอย่าง** ในทุกบท (อยู่ใต้การ์ดในขั้น "เรียน")
- **ระดับภาษา:** แบบสุภาพ (です・ます) เป็นหลัก + บอก**แบบกันเอง**คู่กันเมื่อต่างกันชัด
- **โรมาจิ:** แสดงตลอด แต่มีปุ่ม "ซ่อนโรมาจิ" — ค่าตั้งเดียวกันทั้งสายชีวิตประจำวันและสายท่องเที่ยว
- **ขอบเขต:** 9 ช่วง ทยอยเปิดทีละ 3 ช่วง

## สิ่งที่ต่างจากสายท่องเที่ยว

- **แบบกันเอง:** ใส่ `casual: '<markup>'` ใน `p()` → การ์ดมีกล่อง "แบบกันเอง (เพื่อน · คนสนิท)" พร้อมปุ่มฟัง
  - ใส่เฉพาะวลีที่แบบกันเองต่างจากแบบสุภาพชัดและใช้จริง (เช่น おはよう · ありがとう · 行かない？)
  - ไม่เป็นข้อสอบ — แบบฝึกและแบบทดสอบใช้แบบสุภาพอย่างเดียว
- **บทสนทนาตัวอย่าง:** บทเขียนด้วย `dialogLesson(id, ชื่อญี่ปุ่น, ชื่อไทย, วลี, { scene, lines })`
  - แต่ละบรรทัด `d('a' | 'b', ชื่อผู้พูด, markup, คำแปล)` · `b` = ผู้เรียน (ฟองขวา) · `a` = คนญี่ปุ่น (ฟองซ้าย)
  - บรรทัดละ 1 ประโยค · อย่างน้อย 4 บรรทัด และมีทั้ง 2 ฝั่ง (เทสต์ตรวจ)
  - ปุ่ม "ฟังทั้งบท" อ่านต่อกันทีละบรรทัด (ระดับเสียงต่างกันเล็กน้อยระหว่าง 2 ฝั่ง) · ฟังทีละบรรทัดได้
  - ควรใช้วลีของบทนั้นในบทสนทนาให้มากที่สุด แต่มีประโยคเชื่อมอื่นได้ (มีคำอ่านและคำแปลครบ)
- **ชื่อคนในตัวอย่าง:** ผู้เรียนชื่อ ソムチャイ (สมชาย) · ชื่อเขียนเป็นคาตาคานะ ใส่ `/` แยกโรมาจิ (`ソムチャイ/さん`)

## ข้อมูล (`src/data/daily/` · ส่วนกลาง `src/data/phrase/`)

- **ไฟล์:** ไฟล์ละ 1 ช่วง (`manaa.ts` · `jikoshoukai.ts` · `sasou.ts` · `zatsudan.ts` · `shigoto.ts` · `denwa.ts`)
  รวมใน `index.ts` (`DAILY_DECK`)
- **markup และโรมาจิ:** เหมือนสายท่องเที่ยว (ดู `docs/travel-plan.md`) และเพิ่ม
  - แยก ですね · ですよ · ましょうか · ませんか ให้เอง
  - `…` ท้ายประโยค (ประโยคค้าง เช่น ちょっと…) → โรมาจิ `...`
  - は ที่เป็นท้ายคำอ่านของคันจิ (เช่น `{母|はは}`) ไม่อ่านเป็น wa
- **ส่วนกลางของสายวลี** (ใช้ทั้งท่องเที่ยวและชีวิตประจำวัน)
  - ข้อมูล: `src/data/phrase/` (`types.ts` · `build.ts` = `p()` `d()` `dialogLesson()` `buildPhraseDeck()`)
  - หน้าจอ: `src/features/phrase/` (`PhraseLesson` · `PhraseReview` · `PhraseCards` · `PhraseRunner` · `DialogueCard` · `phraseLogic`)
  - หน้าของแต่ละสาย (`src/pages/Daily*Page.tsx` · `Travel*Page.tsx`) เป็นแค่ตัวห่อ ส่งชุดข้อมูล สี และ path

## กติกาเนื้อหา (ตรวจด้วยเทสต์ `src/data/daily/daily.test.ts`)

- เหมือนสายท่องเที่ยว: ความหมายไทยไม่ซ้ำ · บทละ 5–8 วลี มีวลีที่พูดอย่างน้อย 3 · ข้อเรียงวลี 3 ชิ้นขึ้นไป · `avoid`
- คำอ่าน/โรมาจิของแบบกันเองและบทสนทนาตรวจแบบเดียวกับวลีหลัก
- **จุดที่ควรให้ผู้รู้ช่วยดู:** ตาราง `DAILY_PRIORITY` ใน `scripts/content-review-priority.mjs`
  (ความเป็นธรรมชาติของบทสนทนา · ระดับความสุภาพ · ธรรมเนียม เช่น お疲れさま いってらっしゃい การปฏิเสธ)

## เปิดช่วงใหม่

1. เขียนไฟล์ช่วงใน `src/data/daily/` แล้วแทน `segment(...)` ว่างใน `index.ts` (ลำดับเดิม)
2. แก้จำนวนบทใน `src/data/lineMeta.ts` (`daily`)
3. `npx vitest run src/data/daily src/features/phrase src/data/lineDecks.test.ts`
4. `npm run data:kanji-font` · `npm run content:review` + `DAILY_PRIORITY` ใน `scripts/content-review-priority.mjs`
