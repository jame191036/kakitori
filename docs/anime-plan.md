# แผนสายการ์ตูน / ซีรีส์

หมวด "ดูการ์ตูน / ซีรีส์" บนหน้าแรก (`/anime`) — สำนวนที่ได้ยินบ่อยในการ์ตูนและซีรีส์ญี่ปุ่น และวิธีพูดแบบการ์ตูน
เรียนเป็นสายวลีแบบเดียวกับสายท่องเที่ยว/ชีวิตประจำวัน (ความคืบหน้า `ProgressData.scripts['anime']` · สถานี A01…)

## สิ่งที่ผู้ใช้เลือก (2026-11-24)

- **เนื้อหา:** สำนวนที่ได้ยินบ่อย + วิธีพูดแบบการ์ตูน (คำอุทาน · คำต่อท้ายชื่อ · คำแทนตัว · คำลงท้าย · ภาษาวัยรุ่น · ฉากโรงเรียน ต่อสู้ ความรัก แฟนตาซี)
- **รูปแบบ:** สายบทเรียนแบบเดิม (เรียน → ฝึก → ทดสอบ → ตรา) + **ฉากตัวอย่าง** สั้นๆ ทุกบท
- **ระดับภาษา:** แบบกันเองเป็นหลัก (แบบที่ตัวละครพูด) + **แบบสุภาพ**คู่กัน · คำหยาบหรือคำที่ห้ามพูดจริงมี**คำเตือน**
- **เมนู:** ปุ่ม "ท่องเที่ยว" ในเมนูหลักเปลี่ยนเป็น **"บทสนทนา"** (`/talk`) = หน้ารวมสายวลี 3 สาย (ท่องเที่ยว · ชีวิตประจำวัน · การ์ตูน)
  - เมนูล่างยังเป็น 5 ปุ่ม · เส้นทางของ 3 สายเป็น หน้าแรก › บทสนทนา › สาย · URL เดิมไม่เปลี่ยน · หน้าแรกยังแสดง 3 หมวดแยกกัน
- **ขอบเขต:** 9 ช่วง ทยอยเปิดทีละ 3 ช่วง

## ลิขสิทธิ์

ตัวละคร (ハルト ฮารุโตะ · サクラ ซากุระ · ケンタ เคนตะ · アオイ อาโออิ · รุ่นพี่ยูกิ ฯลฯ) ฉาก และประโยคทั้งหมด**แต่งขึ้นเอง**
ไม่ยกประโยค ชื่อตัวละคร หรือฉากจากการ์ตูนเรื่องใด — สำนวนที่สอนเป็นภาษาทั่วไปที่ได้ยินในการ์ตูนหลายเรื่อง

## ข้อมูล (`src/data/anime/` · ส่วนกลาง `src/data/phrase/`)

- **ไฟล์:** ไฟล์ละ 1 ช่วง (`reaction.ts` · `yobikata.ts` · `hanashikata.ts` · `gakkou.ts` · `tomodachi.ts` · `tatakai.ts` ·
  `renai.ts` · `fantasy.ts` · `oyakusoku.ts`)
  รวมใน `index.ts` (`ANIME_DECK`)
- **ตัวช่วย `p()` เพิ่ม 2 ตัวเลือก** (ใช้ได้ทุกสายวลี)
  - `polite: '<markup>'` = แบบสุภาพ → การ์ดมีกล่อง "แบบสุภาพ (คนไม่สนิท · ผู้ใหญ่)" (คู่กับ `casual` ของสายชีวิตประจำวัน)
  - `caution: '<ข้อความ>'` = กล่องเตือนสีชาดบนการ์ด (คำหยาบ · ภาษาการ์ตูนที่ชีวิตจริงไม่ใช้)
- **ชนิดวลี:** "พูด" = ใช้กับเพื่อนได้จริง · "ได้ยิน" = คำหยาบ/คำห้วน/ภาษาการ์ตูน ฟังให้เข้าใจพอ (ไม่มีข้อให้เลือกพูด)
- **ฉากตัวอย่าง:** ใช้ `dialogLesson` + `d()` เหมือนสายชีวิตประจำวัน · `buildPhraseDeck({ …, dialogueLabel: 'ฉากตัวอย่าง' })`
  เปลี่ยนหัวข้อกล่อง · ฝั่ง b = ตัวเอก (ฟองขวา) · ผู้พูดฝั่งเดียวกันเปลี่ยนชื่อได้
- **โรมาจิ:** เหมือนสายอื่น และเพิ่ม
  - เครื่องหมายท้ายแปลงทีละตัว: `！？` → `!?` · `…` → `...`
  - คำลงท้ายแยกด้วย `/` (`{行|い}く/ぞ！` → iku zo · `そう/っす` → sou ssu · `そう/な/の` → sou na no)
  - **ห้ามจบคำด้วย っ ตัวเล็ก** (えっ ちぇっ) — ไม่มีโรมาจิมาตรฐาน ตัวแปลงจะแจ้งข้อผิดพลาด

## กติกาเนื้อหา (ตรวจด้วยเทสต์ `src/data/anime/anime.test.ts`)

- **คำแทนตัวคงที่ตามตัวละคร:** ฮารุโตะ = 僕 (ผม) · เคนตะ เร็น = 俺 (แปลว่า "ฉัน") · ซากุระ = あたし — "ข้า" ใช้เฉพาะ わし และคนแปลกหน้าในป่า

- เหมือนสายวลีอื่น: ความหมายไทยไม่ซ้ำ · บทละ 5–8 วลี มีวลีที่พูดอย่างน้อย 3 · ข้อเรียงวลี 3 ชิ้นขึ้นไป · `avoid`
- ความหมายไทยบอกน้ำเสียง/ใครพูดในวงเล็บ (ผู้ชาย ห้าวๆ · ผู้หญิง นุ่มนวล · ด่าแรง) เพราะความหมายตรงตัวมักเหมือนกัน
- คำด่า/คำห้วนที่ห้ามพูดจริงต้องเป็นชนิด "ได้ยิน" และมี `caution` (เทสต์ตรวจรายการ)
- วลีที่ใช้แทนกันได้ใส่ `avoid` (うそ ↔ マジで ↔ まさか · いいよ ↔ いいぜ ↔ いいわよ · てめえ ↔ 貴様 · お前 ↔ 君)
- **จุดที่ควรให้ผู้รู้ช่วยดู:** `ANIME_PRIORITY` ใน `scripts/content-review-priority.mjs`

## เปิดช่วงใหม่

1. เขียนไฟล์ช่วงใน `src/data/anime/` แล้วแทน `segment(...)` ว่างใน `index.ts` (ลำดับเดิม)
2. แก้จำนวนบทใน `src/data/lineMeta.ts` (`anime`)
3. `npx vitest run src/data/anime src/features/phrase src/data/lineDecks.test.ts`
4. `npm run data:kanji-font` · `npm run content:review` + `ANIME_PRIORITY`
