# ข้อสอบจำลอง JLPT N5

หน้า `/n5/exam` — ข้อสอบแบบเดียวกับ JLPT N5 จริง ทำได้ทั้งชุด จับเวลา แล้วดูคะแนนพร้อมเฉลยละเอียด

## สิ่งที่ผู้ใช้เลือก (2026-11-23)

- **ขอบเขต:** ส่วนความรู้ภาษา (ตัวอักษร คำศัพท์ ไวยากรณ์) และการอ่านก่อน — การฟังทำทีหลัง
  (ต้องพึ่งเสียงภาษาญี่ปุ่นในเครื่องผู้ใช้ และข้อสอบจริงใช้รูปภาพประกอบ)
- **ชุดข้อสอบ:** ชุดตายตัว เริ่ม 2 ชุด (ทำซ้ำแล้วเทียบคะแนนได้ เพิ่มชุดภายหลังได้)
- **เวลาและคะแนน:** จับเวลาตามจริง ปิดได้ · คะแนนเทียบเต็ม 120 พร้อมบอกว่า "น่าจะผ่าน" แบบประมาณการ
- **ตัวช่วย:** ระหว่างสอบไม่มีคำอ่านเหนือคันจิและไม่มีคำแปล — หลังส่งเฉลยทุกข้อพร้อมคำอ่าน คำแปล และเหตุผล

- เว็บ JLPT ไม่ประกาศจำนวนข้อของแต่ละประเภทแล้ว (ลดจำนวนข้อของ N4/N5 ตั้งแต่ ธ.ค. 2020) — ตัวเลขข้างบนเป็นค่าประมาณที่ใช้กันทั่วไป
- **คะแนนจริง:** ส่วนที่ 1+2 เต็ม 120 (ขั้นต่ำ 38) · การฟังเต็ม 60 (ขั้นต่ำ 19) · รวมต้องได้ 80 จาก 180 และผ่านขั้นต่ำทุกส่วน
- **คะแนนในเว็บ:** JLPT ปรับคะแนนตามความยากของแต่ละข้อ (ไม่ได้นับข้อถูก) เว็บจึงเทียบสัดส่วนข้อที่ถูกเป็นเต็ม 120
  - **ยังไม่ผ่าน** = ต่ำกว่า 38 หรือสัดส่วนต่ำกว่า 80/180 (≈ 44%)
  - **เฉียดเส้น** = 44–60%
  - **น่าจะผ่าน** = 60% ขึ้นไป (เผื่อไว้จากเส้นจริง เพราะเป็นการประมาณ)
  - ผลสอบบอกคะแนนรวมโดยประมาณถ้าการฟังได้สัดส่วนเท่ากันด้วย

## กติกาเนื้อหา (ตรวจด้วยเทสต์ `src/data/exam/exam.test.ts`)

- **คันจิ:** ใช้เฉพาะคันจิ N5 พร้อมคำอ่าน และคำอ่านต้องตรงกับคลังคำศัพท์/คันจิ (ตัวตรวจเดียวกับสายไวยากรณ์ — `src/data/testing/n5Readings.ts`)
  - ยกเว้นตัวเลือกผิดในข้อเขียนคันจิ ที่ตั้งใจใช้ตัวที่หน้าคล้ายกัน (字 交 広 庭 床 体 林 付) และไม่ใส่คำอ่าน
  - วันในสัปดาห์ในตารางเขียนย่อ (月・水) · เวลาใช้ตัวเลข (9時) เพราะ 九時 = くじ ไม่อยู่ในคลังคำ
- **ตัวเลือกผิดต้องผิดจริง:** มีคำตอบถูกข้อเดียว ไม่ใช้รูปที่ภาษาพูดใช้ได้เป็นตัวหลอก
  - เช่น 話すのができます ไม่ได้ใส่ เพราะพูดกันจริง
  - ข้อที่คำตอบขึ้นกับเวลาต้องมีคำบอกเวลาในประโยค (きのう / 来年)
- **ข้อเรียงประโยค:** ชิ้นทั้ง 4 ต้องเรียงได้แบบเดียว
  - หลีกเลี่ยงส่วนขยายที่สลับที่ได้ (いっしょに · ที่ไหน + เมื่อไร)
- **ข้ออ่านคันจิ:**
  - คำตอบ = คำอ่านของคำที่ขีดเส้นใต้ (เทสต์ตรวจ)
  - ตัวหลอกเป็นเสียงยาว/สั้น ขุ่น/ไม่ขุ่น หรือตัวเล็ก
- **ข้อเขียนคันจิ:** คำตอบสะกดคำที่ขีดเส้นใต้ได้ตรง (เทสต์ตรวจ) ส่วนตัวหลอกต้องสะกดไม่ได้
- **ตำแหน่งคำตอบ:** กระจายครบทั้ง 4 ตำแหน่ง
- **ไม่ซ้ำ:** ไม่ใช้โจทย์ซ้ำกันระหว่างชุด

## การทำงานของหน้า

- **ทำทีละส่วน:**
  - ส่วนที่ 1 → พัก → ส่วนที่ 2 → ผลสอบ
  - ส่งส่วนแล้วกลับไปแก้ไม่ได้ · ข้อที่ไม่ได้ตอบนับเป็นข้อผิด
- **ระหว่างทำ:**
  - ทีละข้อ เปลี่ยนคำตอบได้
  - กระโดดไปข้ออื่นได้จาก "ข้อทั้งหมดในส่วนนี้"
  - คีย์ลัด 1–4 เลือกคำตอบ · ← → เลื่อนข้อ
- **จับเวลา:**
  - เวลาที่หมดเก็บเป็นเวลาจริง (deadline) จึงเดินต่อแม้ปิดหน้า เหมือนสอบจริง
  - หมดเวลาแล้วส่งให้อัตโนมัติ รวมถึงตอนกลับมาเปิดหน้าหลังหมดเวลา
- **ข้อมูลในเครื่อง:** `jp-learn:exam:v1` (`src/features/exam/examStore.ts`) เก็บข้อสอบที่ทำค้าง (1 ชุดต่อครั้ง) และผลสอบ 50 ครั้งล่าสุด
  - ยังไม่อยู่ในไฟล์สำรองความคืบหน้า
- **การนับกิจกรรม:** ทำเสร็จแล้วนับเป็นกิจกรรมรายวันเท่าจำนวนข้อที่ตอบ (เป้ารายวัน / streak)
- **การโหลด:** ข้อมูลข้อสอบโหลดแยกเฉพาะหน้า N5 / ข้อสอบ — ESLint ห้าม import `/data/exam/n5` จากไฟล์ก้อนหลัก

## เพิ่มชุดใหม่

1. สร้าง `src/data/exam/n5/set3.ts` ตามแบบ set1/set2 แล้วต่อท้าย `EXAM_SETS`
   - id ของชุดและข้อห้ามเปลี่ยน เพราะผลสอบในเครื่องอ้างถึง
2. `npx vitest run src/data/exam` — เทสต์ตรวจจำนวนข้อ คันจิ คำอ่าน ข้อเรียงประโยค ฯลฯ
3. ถ้ามีคันจิใหม่ (ตัวหลอกในข้อเขียนคันจิ): `npm run data:kanji-font`
4. `npm run content:review` แล้วเพิ่มข้อที่ไม่แน่ใจใน `EXAM_PRIORITY` (`scripts/content-review-priority.mjs`)
