# แผนสายท่องเที่ยว

หมวด "ใช้ท่องเที่ยว" บนหน้าแรก (`/travel`) — วลีที่ใช้จริงตอนเที่ยวญี่ปุ่น เรียนเป็นสายบทเรียนแบบเดียวกับสาย N5
(ช่วง → บท (สถานี) → วลี · ความคืบหน้าเก็บตาม id ของวลีใน `ProgressData.scripts['travel']`)

## สิ่งที่ผู้ใช้เลือก (2026-11-23)

- **หมวดแรกบนหน้าแรก:** ใช้ท่องเที่ยว (ก่อนชีวิตประจำวันและการ์ตูน)
- **รูปแบบ:** สายบทเรียนแบบ N5 (เรียน → ฝึก → ทดสอบ → ตรา · มีรอบทบทวน)
- **การแสดงผล:** คานะตัวใหญ่ + แบบเขียนจริงตัวเล็ก + โรมาจิแสดงตลอด + ปุ่มฟังเสียงทุกวลี
- **ขอบเขต:** 10 ช่วง (รวมช่วง "ป้ายที่เห็นบ่อย") ทยอยเปิดทีละ 3 ช่วง
- **ชนิดวลี:** ทั้ง "ประโยคที่พูด" และ "ประโยคที่จะได้ยิน" จากพนักงานหรือประกาศ (ภาษาสุภาพพิเศษ — แค่ฟังให้ออก)

## ข้อมูล (`src/data/travel/`)

- **ไฟล์:** ไฟล์ละ 1 ช่วง เขียนด้วยตัวช่วย `p(id, markup, thai, { hear, sign, note, arrange, romaji, avoid })`
  จาก `src/data/phrase/build.ts` (ส่วนกลางของสายวลี ใช้ร่วมกับสายชีวิตประจำวัน)
- **markup:** แบบเดียวกับประโยคไวยากรณ์
  - `{漢字|かな}` = คันจิพร้อมคำอ่าน · ช่องว่าง = แบ่งชิ้น (คานะตัวใหญ่เว้นวรรคตรงนี้)
  - `/` = จุดเว้นวรรคของโรมาจิภายในชิ้น (ไม่แสดงในตัวญี่ปุ่น) เช่น `しんじゅく/まで` → shinjuku made
- **โรมาจิ:** สร้างอัตโนมัติจากคานะ (`kanaToRomaji` ของสายคำศัพท์)
  - は / へ / を ท้ายชิ้นอ่านตามเสียงคำช่วย (wa / e / o)
  - แยก です · ですか · ますか · でした ให้เอง · 、 = ,
  - อ่านแบบอัตโนมัติไม่ได้ ใส่ `romaji` เอง (เช่น こんにちは = konnichiwa)
- **คันจิ:** ไม่จำกัดแค่ N5 (วลีจริง) แต่ต้องมีคำอ่านทุกตัว · ชื่อสถานีเขียนเป็นคานะ

## กติกาเนื้อหา (ตรวจด้วยเทสต์ `src/data/travel/travel.test.ts`)

- **ความหมายไทย:** ไม่ซ้ำกันทั้งสาย เพราะใช้เป็นตัวเลือก — หลีกเลี่ยงวลีที่ความหมายทับกัน
  - เช่น ไม่ใส่ ちょっと まって ください คู่กับ 少々お待ちください
- **ขนาดบท:** บทละ 5–8 วลี และต้องมีประโยคที่พูดอย่างน้อย 3 วลี (ยกเว้นบทป้าย ซึ่งเป็นป้ายล้วน)
- **ข้อเรียงวลี:** ใช้เฉพาะประโยคที่พูด ที่ทำเครื่องหมายไว้ (เรียงได้แบบเดียว) และต้องมี 3 ชิ้นขึ้นไป
- **ตัวเลือกผิด:** ไม่ใช้วลีที่ซ้อนกับคำตอบ (`phrasesOverlap` ใน `features/phrase/phraseLogic.ts`)
  - คานะซ้อนกัน เช่น いくらですか กับ しんじゅくまで いくらですか
  - หรือระบุ `avoid` ไว้ในข้อมูล (ใช้แทนกันได้ในบางสถานการณ์)

## แบบฝึกและแบบทดสอบ (`src/features/phrase/` — ส่วนกลางของสายวลี)

- **เรียน:** การ์ดทีละวลี (ป้ายพูด/ได้ยิน · คานะ · แบบเขียนจริง · โรมาจิ · ความหมาย · วิธีใช้ · เสียง)
  - ปุ่ม "ซ่อนโรมาจิ" บนการ์ดและบนโจทย์ (จำค่าไว้ ใช้ทุกสายวลี)
- **ฝึก:** วลีละ 2 ข้อ
  - วลีที่พูด: เลือกวลีที่ควรพูด + เรียงวลี (หรือฟัง)
  - วลีที่ได้ยิน: ฟังแล้วเลือกความหมาย + อ่านแล้วเลือกความหมาย
- **ทดสอบ/ทบทวน:** วลีละ 1 ข้อ
  - วลีที่พูด: เลือกวลีที่ควรพูด
  - วลีที่ได้ยิน: ฟังแล้วเลือกความหมาย
- **ไม่มีเสียงญี่ปุ่นในเครื่อง:** ข้อฟังเปลี่ยนเป็นอ่านแล้วเลือกความหมาย
- **การโหลด:** ข้อมูลโหลดแยกจากก้อนหลัก
  - หน้าแรก/หัวเว็บใช้ `useLineDecks()` — ESLint ห้าม import `data/travel` ตรงๆ
  - จำนวนบทอยู่ใน `src/data/lineMeta.ts` (มีเทสต์)
- **เส้นทางเรียนต่อ:** หน้าแรกชี้สายท่องเที่ยวได้เหมือนสาย N5 · หน้าทบทวนมีการ์ดและนับวลีที่ถึงรอบ
