# รายการทดสอบบนอุปกรณ์จริง

ใช้ทดสอบหลัง deploy ขึ้น Vercel แล้ว — **ไม่ต้องรู้ภาษาญี่ปุ่น** ทำตามได้เลย
ถ้าเจอปัญหา ให้จด: **เครื่องรุ่นอะไร / เบราว์เซอร์อะไร / ทำอะไร / เห็นอะไร** (ถ่ายภาพหน้าจอได้ยิ่งดี)

อุปกรณ์ที่ควรลอง (เท่าที่มี): มือถือ Android (Chrome), iPhone (Safari), แท็บเล็ต/iPad (ถ้ามีปากกายิ่งดี), คอมพิวเตอร์

## 1. การเขียน (สำคัญที่สุด)

- [ ] หน้า **คัดตัวอักษร → เขียนทับ**: ลากนิ้วตามเส้นจาง — หน้าจอ**ไม่เลื่อน**ตามนิ้ว และเส้นตามนิ้วทัน ไม่สะดุด
- [ ] เขียนตามเส้นจางครบทุกขีด → ขึ้นว่า “เยี่ยมมาก! เขียนถูกทุกขีด”
- [ ] ลองเขียน**ข้ามขีด** (เช่นเขียนขีดที่ 2 ก่อน) → ขึ้นว่า “ลำดับขีดผิด”
- [ ] ลองเขียน**กลับทิศ** (ลากจากปลายเส้นกลับไปต้นเส้น) → ขึ้นว่า “ทิศทางผิด”
- [ ] โหมด **ตรวจทีละขีด** (ไม่มีเส้นนำ): เขียนตามแอนิเมชันที่ดูมา — รู้สึกว่าตรวจ**ง่ายไป / ยากไป / พอดี**? ลองเปลี่ยนความเข้มงวด ง่าย / ปกติ / เข้ม
- [ ] โหมด **เขียนอิสระ**: เขียนทั้งตัวแล้วกด “ตรวจ” — คะแนนดูสมเหตุสมผลไหม (เขียนสวยได้คะแนนสูง เขียนมั่วได้คะแนนต่ำ)
- [ ] ถ้ามี**ปากกา** (iPad / แท็บเล็ต): เขียนด้วยปากกาได้ไหม วางมือบนจอระหว่างเขียนแล้วเกิดเส้นแปลกๆ ไหม
- [ ] บนคอม: เขียนด้วย**เมาส์**ได้

## 2. เสียง

- [ ] มี**ปุ่มลำโพง**ข้างตัวอักษรไหม (ถ้าไม่มีเลย = เครื่อง/เบราว์เซอร์นี้ไม่มีเสียงภาษาญี่ปุ่น — จดรุ่นเครื่องไว้)
- [ ] กดแล้วมีเสียง — ฟังแล้วใกล้เคียงกับโรมาจิที่เขียนไว้ไหม (เช่น か ควรได้ยินประมาณ “คะ”)
- [ ] ปุ่มลำโพงของ**คำตัวอย่าง**อ่านทั้งคำ

## 3. แบบทดสอบ

- [ ] ทำแบบทดสอบ 1 รอบ (เลือกรูปแบบคำถามหลายแบบ) จนจบและเห็นหน้าผลคะแนน
- [ ] ข้อแบบ**เขียนตอบ**: เขียนบนกระดานได้ปกติ และปุ่ม “ไม่รู้ / ดูเฉลย” ทำงาน
- [ ] ข้อแบบ**ฟังเสียง** (ถ้าเครื่องมีเสียง): เสียงเล่นเองตอนขึ้นข้อใหม่
- [ ] หน้า**คาตาคานะ**: ข้อสอบแบบจับคู่ “ดูฮิรางานะ → เลือกคาตาคานะ”

## 4. ปุ่ม “เรียนต่อ” และความคืบหน้า

- [ ] เปิดเว็บครั้งแรก เห็นแถบ “เพิ่งเริ่มเรียนภาษาญี่ปุ่น?” และกดปิดได้
- [ ] ฝึกเขียนครบ 1 แถว (เช่น あ い う え お) → มีปุ่ม “ทดสอบแถว あ” ขึ้นมา → สอบผ่าน → การ์ด “เรียนต่อ” พาไปแถว か
- [ ] **ปิดเบราว์เซอร์แล้วเปิดใหม่** → ความคืบหน้ายังอยู่

## 5. ติดตั้งเป็นแอป & ใช้ออฟไลน์

- [ ] Android (Chrome): เมนู ⋮ → “ติดตั้งแอป” / iPhone (Safari): ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
- [ ] ไอคอนแอปบนหน้าจอดูดี (ตัว か สีขาวบนพื้นแดง)
- [ ] เปิดเว็บสักครั้งตอนมีเน็ต แล้วเปิด**โหมดเครื่องบิน** → เปิดแอปจากไอคอน ยังใช้งานได้

## 6. หน้าตาและการใช้งาน

- [ ] หมุนจอเป็นแนวนอน — หน้าไม่พัง
- [ ] เปลี่ยน**โหมดมืด** (ปุ่มขวาบน) — อ่านง่าย มองเห็นเส้นจางชัด
- [ ] ตัวหนังสืออ่านง่าย ปุ่มกดง่าย ไม่เล็กเกินไป
- [ ] กดปุ่ม **ひらがな / カタカナ** ด้านบน — สลับชุดได้ และยังอยู่หน้าเดิม

## 7. พิมพ์แบบฝึก (บนคอม)

- [ ] หน้า **พิมพ์แบบฝึก** → กด “พิมพ์ / บันทึก PDF” → ดูตัวอย่างก่อนพิมพ์ เต็มหน้า A4 สวย ไม่มีเมนูเว็บติดไปด้วย

## 8. ลิงก์ตรง (เช็คการตั้งค่า Vercel)

- [ ] คัดลอกลิงก์หน้าใดก็ได้ เช่น `/katakana/quiz` แล้ววางเปิดในแท็บใหม่ → เปิดได้ ไม่ขึ้น 404
- [ ] อยู่หน้าไหนก็ได้ แล้วกด**รีเฟรช** → ยังอยู่หน้าเดิม
