# รายการทดสอบบนมือถือจริง

ทำตามได้เลยโดย **ไม่ต้องรู้ภาษาญี่ปุ่น** — ข้อที่มี ★ สำคัญที่สุด ถ้ามีเวลาน้อยทำแค่ข้อ ★ ก็พอ (ประมาณ 20–30 นาที)

เรื่องพวกนี้จำลองบนคอมไม่ได้ ต้องลองบนเครื่องจริง: การลากนิ้วเขียน, เสียงอ่าน, ความรู้สึกตอนแตะปุ่ม,
รอยบาก/ขอบจอ iPhone, การติดตั้งเป็นแอป และการใช้ตอนไม่มีเน็ต

## ก่อนเริ่ม

- **เปิดเว็บ:** ใช้ลิงก์ของ Vercel — ลิงก์เว็บจริง (branch `main`) หรือลิงก์ preview ของ branch `dev`
  (Vercel → โปรเจกต์ → Deployments → รายการล่าสุดที่เขียนว่า `dev` → Visit)
- **ให้แน่ใจว่าเป็นเวอร์ชันล่าสุด:** ถ้าขึ้นกล่อง "มีเวอร์ชันใหม่ของเว็บแล้ว" ให้กด **อัปเดต**
  (หรือปิดทุกแท็บของเว็บและแอปที่ติดตั้งไว้ แล้วเปิดใหม่) — รีเฟรชอย่างเดียวยังเป็นของเก่า
- **เครื่องที่ควรลอง (เท่าที่มี):** iPhone (Safari) · มือถือ Android (Chrome) · แท็บเล็ต/iPad (ถ้ามีปากกายิ่งดี)
- **อยากเริ่มแบบผู้ใช้ใหม่:** เปิดแท็บไม่ระบุตัวตน (Private / Incognito) — แต่ข้อ 6 และ 7 ต้องใช้แท็บปกติ

- [ ] 1.4 แตะปุ่มต่างๆ: กดแล้ว**ตอบสนองทันที** ไม่มีกรอบสีเทา/ฟ้ากะพริบตอนแตะ ปุ่มไม่ค้างเป็นสีตอนแตะเสร็จ
- [ ] 1.5 แตะสองครั้งเร็วๆ ที่ปุ่ม: หน้า**ไม่ซูม**เข้าเอง
- [ ] 1.6 ปุ่มลูกศร ‹ มุมซ้ายบน: พากลับไปหน้าก่อนหน้า (ชั้นบน) ได้ถูก

เข้า **ตัวอักษร → ฮิรางานะ → แตะสถานี H01** (หรือปุ่ม "ฝึกเขียน あ ต่อ" ที่หน้าแรก)

- [ ] 2.1 ★ โหมด **เขียนทับ**: ลากนิ้วตามเส้นจาง — **หน้าจอไม่เลื่อนตามนิ้ว** และเส้นตามนิ้วทัน ไม่สะดุด
- [ ] 2.2 ★ เขียนครบทุกขีดโดยไม่ผิด → ขึ้นว่าเขียนถูก และมีตราประทับแดง よくできました ที่มุมกระดาน
- [ ] 2.3 ลองเขียน**ข้ามขีด** (เขียนขีดที่ 2 ก่อน) → ขึ้นว่า "ลำดับขีดผิด" · ลองเขียน**กลับทิศ** → ขึ้นว่า "ทิศทางผิด"
- [ ] 2.4 โหมด **ตรวจทีละขีด** (ไม่มีเส้นนำ): รู้สึกว่าตรวจ **ง่ายไป / ยากไป / พอดี**? ลองเปลี่ยนความเข้มงวด ง่าย / ปกติ / เข้ม
- [ ] 2.5 โหมด **เขียนอิสระ**: เขียนทั้งตัวแล้วกด "ตรวจ" — คะแนนดูสมเหตุสมผลไหม (เขียนสวยได้สูง เขียนมั่วได้ต่ำ)
- [ ] 2.6 ถ้ามี**ปากกา** (iPad/แท็บเล็ต): เขียนด้วยปากกาได้ · วางสันมือบนจอระหว่างเขียนแล้วไม่เกิดเส้นแปลกๆ

- [ ] 4.1 ★ หน้าแผนที่สาย: ช่วงที่ 1 กางอยู่ · แตะหัวช่วงอื่น (เช่น "ตัวเลขและการนับ") → กางออก แตะอีกครั้ง → พับ · แผนที่สถานีในช่วงเลื่อนซ้าย-ขวาด้วยนิ้วได้

## 4A. การ์ตูน / ซีรีส์ ★ (ส่วนใหม่)

เข้า **เมนูล่าง → บทสนทนา**

- [ ] A.1 ★ หน้า **บทสนทนา** มี 3 สาย (ท่องเที่ยว · ชีวิตประจำวัน · การ์ตูน) · ปุ่ม "บทสนทนา" ในเมนูล่างเป็นสีเข้มตอนอยู่ในหน้าของทั้ง 3 สาย
- [ ] A.2 ★ บท **A01 → เรียน**: การ์ดมีกล่อง "แบบสุภาพ" · การ์ดที่ 2 (マジで) มี**กล่องเตือนสีแดง** อ่านชัดทั้งธีมสว่างและมืด
- [ ] A.3 ★ ใต้การ์ดเป็น **ฉากตัวอย่าง** (ฟองแชต) กด "ฟังทั้งบท" ได้ · ปุ่มย้อนกลับบนหัวเว็บพากลับไปหน้าสายการ์ตูน กดอีกครั้งไปหน้า **บทสนทนา**
- [ ] A.4 **ฝึก/ทดสอบ** A01 จนผ่าน → ได้ตรา A01 · หน้าแรก: ป้ายชี้ **A02** และไม่มีหมวดไหนขึ้นว่า "กำลังสร้าง" แล้ว
- [ ] A.5 หน้าสายการ์ตูน: ครบ 9 ช่วง 27 บท · บท **A26**: ฉากมีคนพูด 3 คน อ่านออกว่าใครพูด (ชื่ออยู่เหนือฟอง) ไม่ล้นจอ
- [ ] A.6 ★ บท **A19 → ฝึก**: ก่อนเริ่มเขียนว่า "มีข้อเรียงประโยคเพิ่ม 3 ข้อ" (ไม่มี = ยังเป็นเวอร์ชันเก่า) · ทำจนจบ ข้อเรียงแตะเรียงและแตะเอาออกได้ · ข้อ "เรียงเป็นแบบสุภาพ" มีบรรทัด "ในการ์ตูนพูดว่า…" ไม่ล้นจอ

## 5. ทบทวน

- [ ] 5.1 ★ ในแบบทดสอบคำศัพท์ จงใจตอบผิด 1 ข้อ → ไปหน้า **ทบทวน** (เมนูล่าง) → การ์ด "วันนี้" มีปุ่ม **"ทบทวนคำศัพท์ N5 X คำ"** → กดแล้วเริ่มทบทวนทันที ทำจนจบได้
- [ ] 5.2 หน้า **ทบทวนคำศัพท์ N5**: เห็นจำนวนคำที่ถึงรอบ คำที่ผิดบ่อย และความคืบหน้า 4 ระดับ
- [ ] 5.3 **วันรุ่งขึ้น**หลังทดสอบคันจิ ไวยากรณ์ หรือวลี: หน้า **ทบทวน** การ์ด "วันนี้" มีปุ่มของสายนั้น เช่น **"ทบทวนคันจิ N5 X ตัว"** หรือ **"ทบทวนท่องเที่ยว X วลี"** → กดแล้วเริ่มทบทวนทันที ทำจนจบได้
- [ ] 5.4 ทำแบบทดสอบตัวอักษร (ตัวอักษร → ฮิรางานะ → แบบทดสอบ) จนจบ 1 รอบ และเห็นหน้าผลคะแนน

## 6. ความคืบหน้า เป้ารายวัน และไฟล์สำรอง (ใช้แท็บปกติ)

- [ ] 6.1 ★ **ปิดเบราว์เซอร์แล้วเปิดใหม่** → ความคืบหน้ายังอยู่ (ตรา ป้ายสถานี จำนวนครั้งวันนี้)
- [ ] 6.2 ตอบคำถามหรือเขียนเสร็จครบ 10 ครั้งในวันเดียว → มีแจ้งเตือน "ถึงเป้าวันนี้แล้ว!" · ตั๋วหน้าแรกขึ้น "1 วัน"
- [ ] 6.3 **วันรุ่งขึ้น** ทำให้ถึงเป้าอีกครั้ง → กลายเป็น "2 วัน"
- [ ] 6.4 หน้า **ทบทวน → ทบทวนสายฮิรางานะ → บันทึกไฟล์สำรอง**: ได้ไฟล์ `kakitori-backup-วันที่.json` (จดไว้ว่าไฟล์ไปอยู่ที่ไหน เช่น Downloads / แอป Files)
- [ ] 6.5 ส่งไฟล์ไปอีกเครื่อง (LINE หรืออีเมลถึงตัวเอง) → หน้าเดียวกัน **นำเข้าไฟล์สำรอง** → ขึ้นว่านำเข้าแล้ว และความคืบหน้า (รวมคำศัพท์ คันจิ ไวยากรณ์ การผันคำ และวลี) ตามมา
