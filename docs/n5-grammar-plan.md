# แผนสายไวยากรณ์ JLPT N5

สายไวยากรณ์ใช้โครงเดียวกับสายคำศัพท์และคันจิ คือ ช่วง (区間) → บท (สถานี) → รูปไวยากรณ์ (ความคืบหน้าเก็บตามรูป)

แต่ละบทมีขั้นตอนแบบเดียวกับสายอื่น:

1. **เรียน:** การ์ดรูปละใบ มีรูปประโยค ความหมาย คำอธิบาย และประโยคตัวอย่าง 3 ประโยค (ฟังเสียงได้)
2. **ฝึก:** ประโยคละ 1 ข้อ วนกัน 3 แบบ
   - เติมคำที่หายไป
   - แปลประโยค
   - เรียงประโยค (เฉพาะประโยคที่เรียงได้แบบเดียว)
3. **ทดสอบ:** รูปละ 1 ข้อ เป็นข้อเติมคำหรือข้อแปลเท่านั้น ถูกครบทุกรูปได้ตรา และผลสอบนัดรอบทบทวนให้

บทที่ใช้รูปผันมีกล่อง "ฝึกผันเพิ่ม" ไปสายผันคำ (`src/features/line/formLinks.ts` · ดู `docs/n5-conj-plan.md`)

## สิ่งที่ผู้ใช้เลือก (2026-11-20)

- **รูปแบบ:** สายบทเรียนแบบเดียวกับคำศัพท์และคันจิ
- **ขอบเขต:** ครบชุด (77 รูป) ทยอยเปิดทีละ 3 ช่วง — เปิดครบแล้ว
- **ประโยคตัวอย่าง:** ผู้พัฒนาแต่งเอง ใช้คำศัพท์ N5 ของเว็บ
- **การแสดงผล:** คันจิพร้อมคำอ่านตัวเล็กด้านบน (ふりがな) ซ่อนได้ด้วยปุ่ม

## กติกาเนื้อหา

- **ที่มาของรายการ:** JLPT ไม่มีรายการไวยากรณ์ทางการ รายการนี้ทำตามที่ตำราเรียนระดับต้นทั่วไปสอน
- **คันจิในประโยค:** ใช้เฉพาะคันจิ N5 ทั้ง 103 ตัว คำที่มีคันจินอก N5 เขียนเป็นคานะ (เช่น わたし, としょかん) แบบข้อสอบ N5
  - คำอ่านทุกคำต้องตรงกับคลังคำศัพท์หรือคันจิ ถ้าไม่ตรงต้องใส่ในรายการยกเว้นพร้อมเหตุผล
  - มีเทสต์ตรวจทั้งสองข้อ (`src/data/grammar/grammar.test.ts`)
- **ตัวเลือกผิดในข้อเติมคำ:** ต้องผิดจริงเมื่อเทียบกับคำแปล
  - ไม่ใช้ตัวที่ถูกได้อีก เช่น ข้อ へ ไม่ใส่ に เป็นตัวเลือกผิด เพราะใช้แทนกันได้
  - ไม่ใช้รูปอดีตเป็นตัวหลอกในประโยคที่คำแปลไทยไม่บอกเวลา
- **ข้อเรียงประโยค:** ใช้เฉพาะประโยคที่ทำเครื่องหมายไว้ เพราะภาษาญี่ปุ่นสลับลำดับส่วนขยายหน้าคำกริยาได้
  - ไม่ใช้ในข้อสอบและการทบทวน
- **คำแปลไทย:** ต้องไม่ซ้ำกันทั้งสาย เพราะใช้เป็นตัวเลือกในข้อแปล
- **การตรวจ:** คำอธิบาย ประโยค และคำแปลอยู่ในตารางตรวจเนื้อหา (`npm run content:review`) และยังต้องให้ผู้รู้ภาษาญี่ปุ่นตรวจ
